# Power BI Dashboard Plan

## Dashboard objective
Create a credit-risk dashboard that helps stakeholders understand loan applications and default patterns.

## Page 1 — Executive Overview
KPIs:
- Total applications
- Defaulted applications
- Default rate
- Average loan amount
- Average credit score

Charts:
- Default rate by credit score band
- Default rate by loan purpose
- Default rate by employment status

## Page 2 — Applicant Risk
Charts:
- Default rate by debt-to-income band
- Default rate by income band
- Default rate by late-payment count
- Loan amount distribution

Slicers:
- Loan purpose
- Employment status
- Credit score band
- Income band

## Page 3 — Model Results
Displays:
- Model comparison table
- ROC-AUC
- Precision
- Recall
- F1-score
- Confusion matrix

## Dashboard principle
Use Power BI to communicate findings clearly rather than simply displaying every available metric.
