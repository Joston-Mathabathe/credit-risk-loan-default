# Model Card

## Purpose
Demonstrate a beginner-level credit-risk classification workflow.

## Data
Synthetic loan application data created for this portfolio.

## Target
`default = 1` means synthetic default; `default = 0` means no default.

## Models
Logistic Regression, Decision Tree and Random Forest.

## Limitations
- The data is synthetic.
- The relationships were designed for educational purposes.
- Results do not represent a real bank.
- Model predictions should not automatically determine whether a real customer receives credit.
- A production system would require extensive validation, governance, fairness testing, monitoring and regulatory controls.

## Responsible use
Credit decisions can have significant consequences. A real model should be used with appropriate human oversight, explainability, data governance and validation.
